Overview State Machine comp_overview.c
Replaces boolean ov->active snap with an explicit 4-state lifecycle driven by CompSpring (or curve evaluator) in handle_frame():
StateTriggers & TransitionsInput / Focus Rule
CLOSED Mod+O → OPENING (target=1.0). Tree absent; zero frame wakeups. Normal desktop dispatch.
OPENING Spring 0→1; settles → OPEN. Mod+O/Esc retargets → CLOSING preserving velocity. Accepts nav/hover/click/middle-close without resetting spring.
OPEN Idle at t=1.0. Selection/scroll updates geometry only. Enter/Click/Esc/Mod+O → CLOSING. Full keyboard/pointer nav; 0% idle CPU.
CLOSING On commit=true, focuses target ws/win first so live rects belong to target ws, then zooms 1→0 directly into it. Mod+O retargets → OPENING; destroy tree at settle.
