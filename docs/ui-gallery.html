TOGGLE CARDS (FEATURE TOGGLE WITH STATUS) vs SWITCH ROWS
.toggle-card GtkToggleButton switch
When to use which. A .toggle-card (a GtkToggleButton, state via :checked) is for a feature that has a status line, can be unsupported, or heads its own sub-settings (VRR, Autohide, the Control Center quick tiles). The left indicator bar lights with @metro-accent when on and the body only gets a faint tint so text keeps its contrast. A kajo-switch in a .widget-row-card is for a plain preference whose title and subtitle say everything (mute, word wrap, lock on suspend). Use a segmented-group for 2–4 short mutually exclusive choices; keep dropdowns for longer lists.
